Attendance rules

Handbook 3.6.3: 100% attendance is compulsory per course unit. With a medical recommendation you may sit exams if overall attendance is above 50%. Set the % you want to be warned at (default 80).

The app counts every scheduled lecture hour between these two dates (minus holidays) to work out how many hours you can still miss.

Days before this date use the temporary timetable, this date onwards uses the final timetable.

Holidays / vacation

Lectures on these days are removed from the plan. Use it for public holidays, strikes and the mid-semester vacation week.
